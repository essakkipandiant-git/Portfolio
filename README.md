# Thevar Essakki Pandian — Software Engineer Portfolio

Personal portfolio website for **Thevar Essakki Pandian Murugan**, showcasing engineering projects, technical certifications, professional experience, and contact information.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **UI & Components**: React 19, Lucide Icons, Radix UI Primitives
- **Styling**: Tailwind CSS v4, Custom Design Tokens
- **Animations**: GSAP 3 (ScrollTrigger), Lenis Smooth Scroll
- **Bundler & Tooling**: Vite, TypeScript, ESLint, Prettier

## Features

- **Hero Section**: Dynamic interactive intro with typography, status pill, and featured workspace visual.
- **About Section**: Professional biography, tech stack tags, and authentic portrait visual.
- **Selected Works**: Interactive horizontal project showcase with intuitive arrow navigation and detailed case studies.
- **Certifications**: Responsive grid of verified technical credentials with full-screen lightbox modal preview.
- **Contact & Footer**: Direct communication channels, resume download, and social profiles.

## Development

```sh
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
